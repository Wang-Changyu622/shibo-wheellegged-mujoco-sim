# 用户硬件质量与 CAD 分组审计

用户新提供的卖家图片写明 YT2208 单电机质量 **41 g**、STS3032 单舵机质量 **20.6±1 g**。这两项比参考模型的材料密度归一化更直接，但仍是产品标称值，不是当前实机称重。用户确认使用 2S、7.4 V；电压信息不能推导电池质量，参考电池的 58 g 仍未获实物确认。

当前 336 g 来自参考模型另一台复刻机器。将四个执行器组件替换为上述标称质量、其余零件暂保留原估计后，总质量应为 **317.6494 g**。不能为了继续得到 336 g 而把不相关零件重新放大。317.6494 g 只是“组件质量受规格约束的模型估计”，并非本用户机器的实测总质量。

## 来源与分组证据

每个轮电机目前共 **45.830258 g**，两轮合计91.660516 g。每侧舵机 CAD 子装配包含外壳、内部电机、紧固件等九实体。实体8/17的 STEP 名字虽然也是“电机”，它们是舵机内部电机，不能再当成额外的 YT2208。

独立部件不进入上述质量替换：22/23是左右“舵盘”，各0.889882 g；149/148是左右“2208电机轮胎”，各8.285164 g；142/141是AS5600编码器；146/147是打印小腿壳；132/134等为外部紧固件。按整个 `L_lower` 或 `L_wheel` 缩放会错误改变这些部件，因此不能这样实施。

STEP 轮电机实际命名为 QUANUM 2208，不是 YT2208。相近型号与外形并不能证明内部质量分布相同。41 g 只约束整体电机质量，并不提供定子/转子各自质量、COM 或转动惯量。可复现的暂定做法是保留旧 CAD 的定子/转子比例，明确标成先验；不能声称已由规格辨识该比例。

## 惯量处理：必须重算 COM 和完整张量

锁定的[上游构建脚本](https://github.com/dycsrl/Micro-Wheeled_leg-Robot-Model/blob/a330459b2d3e4567974bb6415abb51086fa5d683/scripts/build_wl_model.py)使用 CadQuery `Shape.matrixOfInertia(shape)` 的 BRep 体积分，转换坐标后按平行轴定理合并。源 XML 为显式 `fullinertia`，不是包围盒惯量。

本次首先独立对OBJ做有向四面体积分。它不能作为无误差的CAD替代：转子19/21的网格体积比STEP清单少2.7233%；轮刚体重建COM相差约0.109 mm、惯量Frobenius相对差约0.32%；舵机壳2/11还有未闭合的网格边。因此正式质量替换使用原始 STEP 的精确 BRep 积分，不使用视觉网格或凸包近似。

对每个受影响刚体，保留源 XML 的原始质量、COM、完整惯量；仅累加各修改实体的 `Δm`、`Δm·c` 和 `Δm·(I_unit + (cᵀc)E − ccᵀ)`，最后由新原点惯量移回新COM。这样不丢弃未修改零件的原始CAD惯量，也不会将整个混合刚体误乘同一个比例。每次更新检查正质量、惯量正定和主惯量三角不等式。

实现与验证已经完成，仅 `hardware_2s` 使用新组件质量；显式 `reference` 保持原336 g。数值记录如下：

- `models/cad_mass_properties.json`：156个保留实体的旧质量、body内质心、每千克完整中心惯量、STEP体积及源文件SHA-256。独立OpenCascade 7.9.3.1.1重新读取本地原STEP，157实体顺序与清单匹配；旧CAD电池实体126按原模型规则排除。
- `docs/evidence/hardware_mass_mapping.json`：四组22实体的STEP产品名、旧/新质量、旧/新中心惯量以及受影响刚体的新COM/完整张量。未提供的定子/转子分重仍显式标成CAD先验。
- `src/wheellegged/mass_properties.py`：`apply_component_mass_profile(root, cad_directory, motor_mass_kg=.041, servo_mass_kg=.0206)` 原位修改内存MJCF五个刚体的inertial。它始终从不可变源XML计算，重复调用不会重复扣减；源XML或清单SHA改变会拒绝使用旧积分表。
- `scripts/export_cad_mass_properties.py`：离线精确BRep导出工具，需要独立CAD Python环境中的`cadquery-ocp`和`numpy`；仿真运行时不依赖CAD库。入口为 `python scripts/export_cad_mass_properties.py --step /path/to/OriginalRobotModel.stp`。

9个原CAD刚体全部重建一致：最大COM差 **5.03×10⁻¹² m**，完整惯量Frobenius最大相对差 **7.12×10⁻¹¹**，处于原XML数值序列化精度范围。新质量MJCF经MuJoCo编译后总质量为 **0.3176493810131978 kg**，所有新惯量正定且满足主惯量三角约束。

回归测试将运行时“源刚体加质量差”算法与“全部156实体围绕新COM直接求和”的独立算法比较，覆盖两组组件质量；同时验证幂等性、源文件错配拒绝、舵盘/轮胎/电池不重复计重以及MuJoCo编译后主惯量。`tests/test_mass_properties.py` 共10项通过；与双profile的`tests/test_model.py`合计54项通过。模型数学一致性不等于真实组件内部密度分布已经辨识。

## 仍需实物确认

- 含当前2S电池、线缆和紧固件的整机总质量及电池质量。
- YT2208是否与该QUANUM CAD的安装尺寸、外转子和连接方式一致。
- 定子与转子的实际分重、转子惯量；仅凭41 g不可推导。
- 舵机标称20.6 g是否含随附舵盘、线缆；CAD中内部件质量分配仍是近似。
- 以实际组件重新标定的COM及轮腿执行器动力学，不应从质量替换自动宣称完成。
