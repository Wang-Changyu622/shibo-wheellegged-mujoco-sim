# 本地验证记录

## 参考模型基线 v2（2026-11-20）

该批结果使用 dycsrl 参考质量/电机近似和本项目控制器，**先于用户补充 YT2208/STS3032 参数与 2S 供电确认**。它证明软件链路与指定参考模型上的行为，不是新硬件参数下已经通过的证据。新硬件模型复验完成后单列结果，旧记录保留。

运行入口：

```bash
.venv/bin/wheellegged run all --output outputs/validated-v2 --video
.venv/bin/python -m pytest -q
.venv/bin/python scripts/check_dynamics.py
```

已执行的默认物理/控制步长为 0.5 ms，MuJoCo 3.17.0、Python 3.14.10、NumPy 2.5.5；真实场景均为自由基座、闭链、接触、四执行器。每步记录状态、执行器输出、轮地力、轮最低点净空和闭链残差。视频从记录的状态回放，不写回仿真。

| 任务 | 结果 | 实测指标 |
|---|---|---|
| 平衡 +0.05 rad 扰动 | PASS | 最终平面位移 2.60 mm，末窗速度峰值约 1.13×10⁻⁶ m/s |
| 前后移动 ±0.12 m/s | PASS | 前进/后退速度 RMSE 0.0186/0.0238 m/s |
| 6 mm 台阶 | PASS（名义条件） | 预伸腿 −0.30 rad、指令0.18 m/s；末轮轴x=0.539 m，非轮支撑=0 |

本批五任务均无非有限状态、MuJoCo求解器警告或非轮部件辅助支撑，闭链最大误差0.161 mm。所有原始控制/力矩边界均通过，但这些边界属于参考模型，不能当作新确认硬件的真实上限。

小型机器可读报告保存在 [reference_v2](../evidence/reference_v2/)。完整每步NPZ、视频、曲线保存在本地 `outputs/validated-v2/<任务>/`。报告内的源文件SHA-256已经与运行时源码核对；这些试验发生在首次Git提交之前，因此原始`git_commit`为null，不能补写一个未运行过的提交号。

## 通过门槛与独立性

一般门槛：全程pitch<0.45 rad、roll<0.25 rad、闭链误差<1 mm；末1 s姿态误差RMS<0.03 rad、速度峰值<0.03 m/s；非轮地面支撑峰值<0.05 N；指令/力矩不越模型限幅。完整阈值在每份JSON及`evaluate.py`中公开。

台阶必须双轮真正到达并停在台面。桥要求左轮在整个中央桥段内处于高台并有支撑，右轮保持地面支撑，随后双轮驶出并回到地面。跳跃要求两轮法向力均<0.02 N，真实圆柱最低点净空均>1 mm，连续时间≥20 ms；相位名为`flight`不能单独使测试通过。评价还包含禁止通过伪造相位、单帧接触丢失和缩短实验时长获得PASS的回归。

**58项自动测试通过**。这不表示所有探索场景都通过：台阶扰动审计在自动基线之外，失败保留如下。

## 已知失败与敏感性

| 台阶条件 | 结果 | 说明 |
|---|---|---|
| dt=0.5 ms、名义初态 | PASS | 非轮接触0 N |
| dt=0.25 ms、名义初态 | PASS | 非轮接触0 N，但横滚接触分支与0.5 ms明显不同 |
| 初始pitch额外−0.01 rad | PASS | 非轮接触0 N |
| 初始pitch额外+0.01 rad | **FAIL** | 下腿短暂顶住阶沿，峰值10.94 N；仍上阶停车，但不满足双轮独立支撑条件 |

因此当前台阶只能报告名义条件成功，不能宣称扰动鲁棒性或完整轨迹的步长收敛。0.25 m/s接近速度也出现下腿顶阶；这些失败没有通过删碰撞或放宽门槛消除。详细数据见 [台阶敏感性](../evidence/reference_v2/step_sensitivity.json)。

1 ms步长下虽然平衡不倒，轮电压尾窗标准差约0.289 V，远高于0.5/0.25 ms的约2.1×10⁻⁵ V；新跳跃守门还会拒绝起跳。因此不支持用1 ms替换默认步长后沿用本页PASS。

## 微跳的物理含义

0.5/0.25 ms下双轮净空峰值为5.630/5.827 mm。独立COM弹道验证中，离地后COM继续上升约2.457/2.416 mm，竖直拟合加速度约−9.812/−9.811 m/s²。轮净空包含收腿贡献，不能当作质心跳高。动力学审查采用更低净空门槛得到约65 ms飞行段，与正式验收的52 ms定义不同，不能混用。
