# 轮腿机器人仿真基线与研究验证计划

日期：2026-11-20。本文是实验设计，列出的实验和阈值尚不等于已执行或已通过。实际结果以保存的配置、日志和报告为准。第一阶段交付目标是可复现的 CAD 闭环机构 + MuJoCo + ROS 2 + 传统控制基线；不能仅凭仿真演示承诺达到 RAL 录用水平。额外加速度计及其控制优化留在后续阶段，本阶段不加入该变量。

台阶效果专项诊断后的实施顺序，见新增的[学习控制计划](learning_control_plan.md)、[代码审查](code_review_next_stage.md)和[台阶诊断](step_diagnostics.md)。下文保留整体研究验证框架；具体阶段以新计划为准。

## 1. 当前要回答的问题

1. 在明确的质量、惯量、接触、轮电压模型与舵机包络下，原结构能否自由基座平衡和正反向行驶？
2. 轮平衡与左右腿高度控制能否处理指定尺度的单边桥、台阶，并在结束后恢复稳定？
3. 在相同执行器约束下，能否实现双轮真实离地、可测净空、落地后稳定的跳跃？若不能，限制来自几何、力矩、速度、功率、接触还是控制？
4. 成功是否依赖单一初始条件、特定步长、真值状态或预知地形？改变这些条件后边界在哪里？

“保持动画姿态”“暂时不倒”“调大电机后跳起”“锁住自由基座”都不能替代以上问题的证据。失败结果与成功结果一同归档。

## 2. 研究贡献应如何形成

本项目参考机构建模、LQR、高度调节和混合跳跃相位均有已有实现。它们构成实验基础，不预先声明为新算法。完成基线后，才选择一个有明确假设、可验证收益和可对照代价的研究问题，例如：

| 待验证方向 | 必须给出的新证据 | 不能作为贡献的内容 |
|---|---|---|
| 位置舵机与轮电压限制下的接触切换控制 | 执行器约束模型、可行工作区、相位切换准则，以及相同限制下显著更宽的任务成功域 | 把开源相位机重命名；默认实机可直接输出力矩 |
| 四杆机构姿态变化下的模型与控制一致性 | 可重复的闭链参数辨识、模型误差量化、误差与稳定裕度的联系，及控制策略的跨姿态收益 | 展示真实外观网格但不校准惯量或闭环误差 |
| 低成本平台在不对称支撑和跳跃中的鲁棒控制 | 明确不确定性集合、与已有方法的公平对比、消融和实机跨工况结果 | 只提供一个摩擦系数和一个漂亮视频 |

最终论文只能选择实际得到证据支持的主线。相关工作需在贡献确定后按具体问题系统检索，明确区别于已有轮腿 LQR/VMC、混合控制、执行器约束控制研究；这份计划不是文献综述或创新性认证。

## 3. 数据来源与模型可信度

来源和固定提交见 [reference_review.md](reference_review.md)。0.336 kg 总质量和 0.058 kg 电池质量属于参考作者的复刻平台，不是当前实物已称量。默认hardware_2s已按用户电机/舵机规格替换相应组件质量，估计总质量0.317649381kg；其余组件和电池仍是先验。所有未标定参数在配置中标注为假设，保留原值、修改理由和有效范围。

模型验收先于控制验收：

- 核验 STEP/网格/参数 SHA-256、单位、轮半径、轮距、关节轴和四杆分支；零位必须区分 CAD 零位、机械装配零位与舵机计数零位。
- 检查质量和惯量物理有效性、总质量、COM 位置、装配约束残差、关节可行区间；站立承重与空载动作分别验证。
- 测量整个轨迹的轮地/非轮地接触、最大穿透、四杆闭环残差和警告。接触点数、零警告都不能单独证明正确。
- 保留位置舵机和轮电压语义，记录角度/速度/力矩饱和。为研究使用其他执行器包络时另设配置，不能悄悄改变基线。
- 以相同物理时间比较默认步长与半步长；控制周期保持不变，避免把物理积分变化与控制频率变化混为一谈。

第三方资产由 `python3 scripts/fetch_assets.py` 按固定提交下载到 `assets/cad/`，使用 `python3 scripts/fetch_assets.py --check` 校验全部 256 个文件。脚本只下载选定的 MJCF、网格、参数、CAD manifest 和来源说明。`scripts/asset-lock.json` 保存源路径、目标路径、字节数与 SHA-256，资产本体不重新分发；已有修改文件不会被覆盖。离线机器可指定 `--source-dir /path/to/upstream-checkout`。

## 4. 任务定义与验收规则

以下是建议的预注册起点，需先在开发集确认任务尺度和传感器定义，再固定写入配置。若调整阈值，必须记录版本并重跑对照，不能在看到测试集结果后只放宽失败项。微型车轮半径仅 18.5 mm；所有台阶和桥高同时报告毫米数和相对轮半径，不用缩尺障碍暗示能上建筑楼梯。

| 任务 | 建议试验 | 成功需要的实际事件 | 主要指标 |
|---|---|---|---|
| 平衡 | 无扰动 15 s；正负初始 pitch；前后/侧向定量冲量后恢复 | 全程自由基座、无跌倒/机身撑地，末窗回稳 | pitch/roll RMS 与峰值、位置漂移、恢复时间、饱和率 |
| 前后移动 | 站立→正速度→停止→负速度→停止，参考限加速度 | 有真实正负位移；每次停止后稳定 | 速度 RMSE、超调、停车距离、侧漂、yaw 误差 |
| 单边桥 | 左轮进入窄高台、沿台前进、下台；右轮始终走较低地面；左右镜像复验 | 指定轮在桥面形成有效支撑并完整通过，另一轮保持地面支撑，最终回稳 | 通过率、姿态峰值、左右腿目标/实际差、支撑力、离轨次数 |
| 台阶 | 从低平面接近真实竖直边缘并上到高平台 | 两轮轴心均越过前沿，轮底达到平台高度，COM 进入平台且保持稳定 | 最大可通过高度、轮滑移、冲击、通过时间、卡住/翻倒失败模式 |
| 跳跃 | 稳定站立→准备→伸腿→飞行→落地→恢复 | 双轮同时持续无地面支撑，轮底相对当地地形有正净空，随后重新接地并回稳 | 双轮离地持续时间、净空、COM 顶点、落地冲量、姿态和漂移、恢复时间 |

建议跳跃最低事件阈值为双轮离地持续 ≥20 ms、几何净空 ≥2 mm，接触确认同时使用逐轮接触力和轮底到地形的距离，排除软接触边缘数值抖动。此阈值只用于区分跳跃与抖动，实际高度必须单独报告。

建议回稳判据使用连续末窗 2 s，而不是单帧：pitch RMS <5°、|roll| 峰值 <8°、停止任务的 |速度| <0.03 m/s，并给出位置漂移。跌倒判据与原固件 |pitch|>25° 相协调，同时检查 roll 和非轮支撑，不能只防前后倒。以上数值应写为配置项；如硬件能力使任务不可行，报告不可行边界，不降低判据冒充成功。

跳跃与单轮过边缘时，轮编码器线速度不等于机身速度；同时保存这两种量及滑移指标。接触检测必须区分左右轮、地形、自碰撞和机身碰撞，不能用 `data.ncon>0` 代表有效着地。

## 5. 公平对照与消融

对比方法先在同一开发集、同一控制频率、相同执行器/关节限制下调参，再冻结配置。所有方法使用相同初值、扰动、传感器可用性和时延；不允许只给新方法提前知道台阶位置。

| 编号 | 基线或消融 | 检验目的 |
|---|---|---|
| B0 | 原硬件四状态反馈逻辑的 SI 单位移植，公开换算和重调参数 | 与原平台控制结构比较；称为逻辑移植而非逐周期等价固件 |
| B1 | 固定站高下重新求解的离散 LQR + 固定腿高 | 测轮平衡本身的能力 |
| B2 | 高度变化下的增益调度 LQR + 双腿位置调节 | 测增益调度及腿调节带来的收益 |
| B3 | B2 + 明确的跳跃/接触相位管理 | 测接触切换与落地恢复的收益 |
| A1 | 固定 LQR 增益，保留其他模块 | 隔离增益调度效应 |
| A2 | 关闭左右腿找平，保留公共高度 | 隔离不对称支撑补偿 |
| A3 | 定时跳跃切换代替接触切换 | 隔离事件驱动相位机作用 |
| A4 | 关闭落地专用控制，保留起跳动作 | 隔离落地恢复作用 |
| A5 | 真值状态与可实现传感器估计分开运行 | 量化真值信息带来的乐观偏差 |

实验数量随最终贡献收敛，不需要为凑表格堆算法。缺乏对应任务能力的基线仍可记录失败，但应提供合理调参预算，不能故意用错单位或旧机器人的增益构造差对照。对地形预览、轮地真值接触和全局位置等信息明确标注“仿真真值”“可测”“估计”或“先验”，不能把真值基线称为无外部感知自主控制。

## 6. 鲁棒性与随机试验

分两层开展：单因素扫描用于解释失效边界，联合随机化用于测量跨工况表现。以下范围是探索建议，最终应根据测量误差与实际使用范围设定，不是已知硬件容差。

| 因素 | 探索起点 | 记录方式 |
|---|---|---|
| 总质量和电池负载 | 名义值 ±10% / ±20% | 质量改变时同步正确更新惯量 |
| COM 偏移 | 前后/左右 ±2–5 mm | 使用真实移动质量或一致惯量变换 |
| 摩擦 | 名义值上下扫描，低摩擦单独分组 | 接触参数、滑移、成功域 |
| 轮驱动力与舵机能力 | 驱动增益/力矩/速度上限减弱 10–30% | 区分控制量饱和与执行器力饱和 |
| 时延与控制抖动 | 0、2、5、10、20 ms | 控制周期、测量时延和命令时延分开 |
| 传感器误差 | 依据 IMU/编码器静态日志设置偏置和噪声 | 使用当前硬件已有传感器；不加入额外加速度计 |
| 初值与外扰 | 正负 pitch/roll、小角速度、不同方向冲量 | 用 N·s 报告冲量，不能只给施力帧数 |
| 地形与接近状态 | 高度/宽度/边缘/横向偏移/速度 | 以毫米、轮半径比和随机种子保存 |

每个算法共享同一组随机样本，采用配对比较。开发种子与最终测试种子分离；只在确定需要随机变量时使用重复试验，同一确定性配置反复跑不能当成独立样本。

开发阶段可先用每工况 30 个随机样本排查；最终样本量按预期效应、计算/实机预算和置信区间宽度确定，不把 30 次视为充分性保证。仿真可采用每工况至少 100 个独立样本作为起点。成功率报告二项 Wilson 95% 区间；连续指标给均值/标准差或中位数/分位数，并用以“试次”为重采样单位的配对 bootstrap 比较差值。不能把每毫秒采样点当成独立统计样本。

失败不能从 RMSE 表中悄悄删除：同时报告所有试次成功率、失败时间，以及仅成功试次的条件指标，并明确其条件性。若比较很多指标/算法，应预先指定主要指标，必要时对多重检验作调整；统计显著性不替代实际收益幅度。

## 7. ROS 2 与复现工程

控制核心应独立于 ROS 2 运行，以便无头回归和数值调试；ROS 2 负责命令输入、状态输出和时钟桥接。验证内容包括单位/坐标系、时间戳单调性、仿真 `/clock`、重置后的时钟处理、命令超时、控制周期与物理步长分离，以及消息延迟对任务的影响。发布 joint state、IMU 和里程计时区分真值与估计，避免把 COM 真值包装成硬件可测量状态。

每次运行至少保存：代码提交、配置文件及哈希、资产锁哈希、MuJoCo/Python/依赖版本、种子、物理步长、控制周期、初值、扰动/地形参数、失败原因、原始时间序列与汇总指标。视频是辅助证据，时间序列和配置才是复算基础。报告仿真时间与墙钟时间、实时系数，不能把离线快跑称为实机实时运行。

建议试验输出分为 `outputs/<experiment>/<run_id>/`，运行后自动生成报告，防止覆盖原始记录。参数搜索与正式评估分目录，最终表格从原始数据生成，保留全部种子索引和失败原因。

## 8. 实机标定和迁移计划

仿真任务完成后再进入实机阶段；先测量再决定模型扩展，避免把全部误差归因于控制器。

1. **机械与质量**：称整机、电池和主要组件，记录电池安装坐标；测轮半径、轮距和关节间隙；在多个腿位姿下估计 COM，核对四杆装配分支与干涉范围。
2. **舵机映射**：测每侧计数→关节角→轮高度曲线，辨认电气零位、迟滞与左右差异；以多负载/多速度输入辨识闭环带宽、饱和、延迟和可持续能力。零速度/零加速度协议值需按实际响应核实。
3. **轮电压模型**：在不同电压、电池状态和负载下测轮速/驱动力，辨识死区、有效电压增益、反电势/阻尼近似、滑移与滚阻。电压命令不能直接宣称为已知力矩；有电流数据时单独记录测量来源。
4. **既有传感器**：测 MPU6050 和轮编码器的采样率、时间戳、偏置/噪声、姿态滤波延迟及安装方向。这里是现有传感器校准，不开展新加速度计优化。
5. **渐进迁移**：先带保护的轮/腿单通道动作和低速平衡，再前后移动、小障碍，最后跳跃；比较同一命令下的仿真/实机轨迹和饱和事件。保护台架会改变动力学，台架成功不得等同于自由站立成功。
6. **外部测量**：使用相机或独立测量系统作评估真值，明确其是否参与控制。实机任务重复次数根据可重复性和损耗预算确定，并如实报告硬件修订和失败。

## 9. 阶段结束条件

第一阶段完成需要：代码整洁可运行、资产来源可复现、六自由度自由基座模型可检查、五类任务有明确配置与真实通过/失败证据、ROS 2 桥接实测、已知局限和后续事项归档。某任务不可行时应交付可复现的失败边界及原因，不能在总结中写成已完成该能力。

之后才决定论文主问题、扩展方法和实机实验。在这些基础稳定前，额外加速度计相关研究保持独立，不改变当前对照基线。
